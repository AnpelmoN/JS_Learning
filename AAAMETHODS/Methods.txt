!1. Добавление и удаление элементов!

push(...items) — добавляет элементы в конец массива — когда пользователь добавляет новый товар в корзину.

pop() — удаляет последний элемент и возвращает его — реализация функции «Отменить последнее действие» (Undo).

shift() — удаляет первый элемент — обработка заявок в очереди (первый пришел — первый обслужен).

unshift(...items) — добавляет элементы в начало — закрепление важного уведомления вверху ленты новостей.

splice(index, deleteCount, ...items) — универсальный метод для вставки, удаления и замены — удаление одного конкретного поста из середины списка по его индексу.

slice(start, end) — копирует участок массива в новый массив — создание превью списка (показать только первые 3 элемента).

concat(...items) — объединяет массивы в один новый — слияние двух списков контактов из разных источников.


!2. Поиск элементов!

indexOf(item) — ищет элемент и возвращает его индекс — проверка, на каком месте в списке находится выбранный город.

lastIndexOf(item) — ищет с конца — поиск последнего упоминания слова в массиве строк.

includes(item) — проверяет, есть ли элемент в массиве (возвращает true/false) — проверка, есть ли у пользователя права «admin» в списке его ролей.

find(callback) — возвращает первый элемент, подходящий под условие — поиск объекта пользователя по его уникальному ID.

findIndex(callback) — возвращает индекс первого найденного элемента — поиск позиции игрока в таблице лидеров, чтобы обновить его статус.

findLast / findLastIndex — то же самое, но с конца массива — поиск последней транзакции пользователя в истории.


!3. Перебор и трансформация!

forEach(callback) — выполняет функцию для каждого элемента — отрисовка каждого элемента массива на странице (простой вывод).

map(callback) — создает новый массив, изменяя каждый элемент — превращение массива цен в массив строк с добавлением значка валюты $.

filter(callback) — создает новый массив из элементов, прошедших проверку — фильтрация товаров, которые стоят дешевле 1000 рублей.

reduce(accumulator, item) — «сворачивает» массив в одно значение — подсчет общей суммы всех товаров в корзине.

reduceRight — то же самое, но справа налево — вычисление значения сложной математической формулы с конца.


!4. Изменение порядка и структуры!

sort(fn) — сортирует массив (по умолчанию как строки) — сортировка списка имен по алфавиту или цен по возрастанию.

reverse() — разворачивает массив задом наперед — переключение отображения комментариев от «старых» к «новым».

split / join — (строковый метод / метод массива) — превращение строки тегов, разделенных запятой, в массив и обратно.

flat(depth) — «выпрямляет» вложенные массивы — превращение [1, [2, 3]] в [1, 2, 3] после загрузки данных из сложного API.

flatMap(callback) — сначала map, потом flat — когда нужно извлечь все хобби из массива пользователей в один общий плоский список.


!5. Копирование и проверка!

fill(value) — заполняет массив статичным значением — создание «болванки» игрового поля 10x10, заполненного нулями.

copyWithin(target, start, end) — копирует часть массива в другое место этого же массива — перестановка элементов в игровом инвентаре без создания копий.

Array.isArray(value) — проверяет, является ли переменная массивом — защита функции от ошибок, если вместо списка пришел одиночный объект.

Array.from(iterable) — создает массив из чего-то похожего на массив — превращение коллекции HTML-узлов (DOM-элементов) в настоящий массив, чтобы использовать map.


!6. Новые методы (ES2023+ и удобство)!

at(index) — возвращает элемент по индексу (поддерживает отрицательные) — получение последнего элемента массива через arr.at(-1) вместо громоздкого arr[arr.length - 1].

toSorted(), toReversed(), toSpliced() — копии методов sort, reverse и splice, которые не меняют исходный массив — когда нужно изменить порядок для отображения, но сохранить оригинал данных в стейте (React/Vue).

with(index, value) — возвращает копию массива с измененным элементом — обновление одного поля в иммутабельном массиве данных.
